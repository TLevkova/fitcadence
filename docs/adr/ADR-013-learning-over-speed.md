# ADR-013 · Learning over delivery speed

## Context

The project has a learning goal alongside the product goal (brief §1), set out as learning objectives L-1 to L-6 in the vision. Vision constraint C-6 records this rule. Time is limited to about 8 hours per week, with no fixed date for the first release (C-12).

## Decision

When learning and delivery speed conflict, the slower, more instructive route wins.

## Consequences

- Where the two conflict, the slower route is taken, even though time is limited (C-12).
- The vision uses this rule as part of the mitigation for Claude Pro usage limits (R-3).
