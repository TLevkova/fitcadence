# FitCadence – Vision

## 1. Problem statement

Teodora trains at home three times a week from her own full-body program (Workouts 1, 2 and 3), which she follows from Markdown files. She has not used a workout-tracking app or a spreadsheet, so there is no easy way to record what she did per set or to see when an exercise is due to progress. Separately, planning meals that hit her daily macros without becoming too strict is hard: it takes meal ideas, balanced protein, fat and carbs, the right products at home, and time and energy to cook. Supplements are taken from memory, shopping lists are phone notes, and Samsung Health is used only for steps. The project is also a vehicle for practising AI-assisted software delivery with Claude Code (see brief, section 1).

## 2. Vision statement

For Teodora, a home trainer who follows her own three-workout full-body program, FitCadence is a personal fitness web app that guides each session block by block and records every set in the breaks between rounds, with a minimal dashboard of what she did, and Meals, Supplements and Tools to follow. Unlike following the program from Markdown files with no record, it shows the next workout with its videos and keeps what she actually did.

### 6.1 Capability areas

| ID    | Capability  | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Release                                                   | Supports      |
| ----- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- | ------------- |
| CAP-1 | Workout     | Show the day's workout block by block, with the block's exercise videos playable before it starts. The workout is the next in the rotation after the last logged workout; deleted or unlogged sessions do not advance it. Log by round: each set (an exercise in a round) is marked done or skipped, with expected reps and load pre-filled from the program and edited only when different; a round or a whole block can also be marked skipped. Each set is marked separately: there is no one-tap "whole round done". A set's load is kg, band tension or support height, set per exercise; tempo is not a load type. A rest timer runs between rounds. Nothing is pre-selected. Round, block and workout status follow from the marks. A started log can be deleted. Add exercises and edit the workout plan and equipment in the UI (rare edits; in the first release; also how her own program is entered, since nothing personal is hardcoded, C-15). Later: free-text note per workout, warm-up shown before block A, return-after-break protocol. Out of the MVP: skip rules or planning, progression hints (G-3), blocked-week tracking | MVP (note, warm-up and return-after-break protocol Later) | G-1, G-2, G-4 |
| CAP-2 | Meals       | Food and recipes with macros; meal suggestions within calorie and nutrient limits; recipes feeding the shopping list                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Later (1st)                                               | –             |

| CAP-4 | Dashboard   | Statistics. MVP: minimal, showing workout done, how many blocks and sets were completed, and logged workouts per week. Later: fuller tracker results, body weight and body measurements                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | MVP (minimal), then Later (3rd)                           | G-4           |

### 6.3 MVP exit criterion

The MVP is done when one real workout has been logged end to end in the private instance, from the next-in-rotation workout to the saved log. C-14 (backup or export) and C-16 (login) apply before real data is entered. Added in P0.2.
